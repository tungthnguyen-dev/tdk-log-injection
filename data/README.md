# Dataset: labelled nginx access logs (v1)

## Files
- `frozen/access_v1.jsonl` — raw nginx log (JSON, one request per line). Never modified.
- `processed/events_labelled.csv` — parsed and labelled events, generated by `scripts/parse_logs.py`.

## How it was generated
- Isolated Docker testbed (`testbed/`): nginx (reverse proxy, JSON access log) in front of a small Flask app.
- Network `labnet` is `internal: true` (no Internet access, verified in `docs/isolation_check.md`).
- Benign traffic: `generators/benign.py`, 500 requests, seed 42, from 172.28.0.10.
- Attack traffic: `generators/attack.py`, 50 requests per class (200 total), seed 43, from 172.28.0.20.
- Both generators ran concurrently.

## Labels
- `label`: derived from source IP (172.28.0.10 = benign, 172.28.0.20 = attack).
- `attack_type`: none | path_scan | sqli | path_traversal | scanner_ua

## Columns
| Column | Description |
|---|---|
| event_id | Unique id, ordered by time (ev00000 ...) |
| time | Request time (ISO 8601) |
| remote_addr | Source IP — **LABEL SOURCE, DO NOT USE AS FEATURE** |
| method | HTTP method (attacker-controlled) |
| uri | Full request URI, raw (attacker-controlled) |
| protocol | HTTP version (attacker-controlled) |
| status | Response status code (server-generated) |
| bytes | Response body size (server-generated) |
| referer | Referer header (attacker-controlled) |
| user_agent | User-Agent header (attacker-controlled) |
| request_time | Processing time in seconds (server-generated) |
| label | benign / attack |
| attack_type | Attack class, `none` for benign |
| raw_log | Original log line as JSON, without the internal `exp_id` field — this is what the LLM sees in condition A |

## Known limitations
- Synthetic traffic: may be easier to classify than real-world traffic.
- Attack requests are sent faster than benign and fall within a short time window; do not use time-based features without accounting for this.
- Some path traversal requests are rejected by nginx itself (400) before reaching the app — expected nginx behaviour.
